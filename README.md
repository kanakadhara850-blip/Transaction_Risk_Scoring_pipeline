# Transaction_Risk_Scoring_pipeline
A Python-based real-time transaction risk scoring system designed to address performance bottlenecks in legacy banking architectures when processing large volumes of transaction audit logs and fraud alerts. The pipeline analyzes transaction behaviour and contextual data to detect anomalous patterns such as geographical jumps, sudden high-value transactions, velocity deviations, unusual transaction frequency, device changes, and network/IP anomalies.
The system uses AI/ML models for behavioural anomaly detection and scam-risk prediction, multiprocessing for parallel transaction processing, TCP socket programming for real-time communication, and SymPy for mathematical risk scoring. Transactions are classified into Low, Medium, and High Risk based on a combined risk score, while an auditable transaction trail is maintained for monitoring and investigation. The system is designed with an approximate 50 ms risk-assessment target and includes a Tkinter monitoring dashboard for real-time visualization.
